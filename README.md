# ⚡ Smart Energy IoT Monitoring System

Асинхронная система мониторинга параметров электросети (напряжение, ток, мощность) в реальном времени с поддержкой интерактивного дашборда и экстренных Telegram-уведомлений при скачках напряжения.

---

## 🛠 Архитектура и стек технологий

- **Python 3.10+** — основной язык разработки.
- **Paho-MQTT** — протокол передачи телеметрии с эмулируемого датчика.
- **Streamlit & Plotly** — веб-дашборд и визуализация графиков в реальном времени.
- **Aiogram 3.x** — асинхронный бот для мгновенной отправки алертов в Telegram.
- **python-dotenv** — управление конфигурацией и секретами.

---
